# Asset Allocation Planner

A premium, lightning-fast web application that helps users strategize their asset allocation against modern macroeconomic risks like Hyperinflation and AI-driven Deflation.

## Features
- **Goal & FIRE Tracking**: Maps your goals and specifically visualizes your Financial Independence / Retire Early (FIRE) status using the 4% safe withdrawal rule.
- **Global Diversification Model**: Automatically suggests ₹ action plans spanning US/India direct equities, mutual funds, real estate, gold, and debt.
- **Resilient AI Strategy**: Recommends a highly-defensive, All-Weather portfolio mathematically designed to protect capital during global crises.
- **100% Client-Side**: No backend, no data collected! Everything runs locally in your browser for maximum security.
