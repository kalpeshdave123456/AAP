How this version works

Recommendation logic

  • Builds target allocation from age, risk profile, retirement horizon, and emergency-fund readiness.
  • Checks goal feasibility using inflation and expected-return assumptions.
  • Scores mutual fund suggestions using category fit, cost, risk, consistency, and support ratings.
  • Shows Value Research and Moneycontrol fields as supporting indicators, not as the sole decision factor.
  • Designed to run fully on GitHub Pages without any backend.
Note: Ratings and fund metadata in this GitHub starter are sample reference values for demo UX. Replace fundData in app.js with your curated dataset or API feed before production use.
